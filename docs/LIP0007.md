# LIP-0007 vs BDK / rust-litecoin

Draft: [DavidBurkett/lips `lip0007`](https://github.com/DavidBurkett/lips/blob/lip0007/lip-0007.mediawiki) (2025-07-25).  
Official [litecoin-project/lips](https://github.com/litecoin-project/lips) still lists only LIP-0001–0006.

Core v24.0.1 implements this draft. The 2026-07-27 ltcd map in [`LTCSUITE_ALIGNMENT.md`](LTCSUITE_ALIGNMENT.md) is the **0.21-era** inventory. **Core + LIP-0007 is the v24 interop target.** Parked on `v24-rmweb`; do not merge to `litecoin` until a public v24 pin.

## Unchanged key codes

| Scope | Codes | Meaning |
| --- | --- | --- |
| Global | `0x90` `0x91` `0x92` | kernel offset, stealth offset, kernel count |
| Input | `0x90`–`0x95`, `0x97`–`0x99`, `0x9C` | output id … extra data |
| Output | `0x90`–`0x98` | stealth … extra |
| Kernel | `0x00`–`0x08` | excess … signature |

675-byte bulletproofs, 64-byte Schnorr (no sighash byte), amounts 8-byte LE.

## Divergences (rewrite)

| Item | BDK / ltcd (2026-07-27) | LIP-0007 / Core v24 |
| --- | --- | --- |
| Container | PSBTv0 + `unsigned_tx` | **v2 only**; MWEB keys on v0 are invalid |
| Kernel maps | Global `0x93` + 4-byte index | Trailing **kernel section** after outputs |
| Parallel MWEB in/out | Global keys (`0x90+` / `0x94`) with index | Real input/output maps; MWEB **after** canonical |
| Input `0x96` | LE u32 address index | ASCII `mweb(...)` descriptor; **ignore** exactly 4 bytes |
| Input `0x9A` / `0x9B` | BIP32 origins `(PublicKey, KeySource)` | **Reserved** — do not emit |
| MWEB input identity | (implicit) | Has `PSBT_IN_MWEB_OUTPUT_ID` |
| MWEB output identity | (implicit) | Has stealth address or commit |
| Canonical requirements | BIP-174 | MWEB inputs omit prevout; MWEB outputs omit script, still need amount |
| Combine | unsigned txid | Structural identity + strict field merge |
| Sign order | (unspecified) | Finalize **all** MWEB first; rewrite peg-in `OP_9 <0…0>`; **then** canonical signatures |

## Roles (LIP-0007)

1. **Creator** — MWEB input maps (output id + known metadata), output maps (stealth + amount), kernel maps (fee / peg-in / peg-out / lock). Peg-in scripts are all-zero placeholders. Offsets absent.
2. **Updater** — `mweb(...)` descriptor + shared secret or key-exchange pubkey.
3. **MWEB signer** — one shot: commitments, proofs, input/kernel sigs, both offsets, rewrite peg-in scripts, clear `TX_MODIFIABLE`.
4. **Canonical signer** — only after step 3 (sighash commits to rewritten peg-in scripts).
5. **Extractor** — verify sigs, range proofs, balance, peg-in IDs; assemble `mw_tx`.

## BDK stance on this branch

- **Emit** LIP-0007: descriptor `0x96`, no origins, PSBTv2 + kernel sections when MWEB maps are present. MWEB outputs carry BIP-370 `PSBT_OUT_AMOUNT`.
- **Read** 4-byte `0x96` as ignore; still ingest ltcd origins via [`psbt_from_ltcd_v2`](../crates/mweb/src/psbt_ltcd.rs) for 0.21-era fixtures.
- rust-litecoin pin: `2e4577f` on `v24-rmweb`. Probe: [`core_psbt_lip0007.rs`](../crates/mweb/tests/core_psbt_lip0007.rs).
- Core golden bytes: `src/test/util/psbt_vectors.h` and `test/functional/mweb_psbt.py` in the v24 tree (cite, do not invent a third map).
